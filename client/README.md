# Adoptly — Frontend 🐾

Interfaz web de Adoptly, una aplicación que conecta a personas que desean adoptar mascotas con refugios, rescatistas y particulares.

## Tecnologías

- React
- JavaScript
- HTML y CSS
- Vite

## Funcionalidades previstas

- Registro e inicio de sesión.
- Listado y búsqueda de mascotas con filtros.
- Consulta del detalle de cada mascota.
- Envío de solicitudes de adopción.
- Gestión de publicaciones y solicitudes del publicador.

## Instalación

Desde la carpeta `client`, instalar las dependencias:

npm install

Iniciar el servidor de desarrollo:

npm run dev

## Commits

Escribir mensajes descriptivos que indiquen claramente qué se modificó.

Ejemplos:

- Agrega el listado de mascotas.
- Crea el formulario de inicio de sesión.
- Corrige la validación del formulario de adopción.
- Mejora la visualización de las tarjetas en celulares.
- Conecta la búsqueda de mascotas con la API.
